# Blackout Box media: prompts and commands

All stills were generated with Grok Imagine (`grok-imagine-image-2.0`) through the grok-imagine skill script, then converted to WebP with PIL.

## Commands

```bash
cd web/scripts/media
python3 gen.py jobs-hero.txt            # 12 Now heroes (2k: 2816x1584 / 1584x2816), 4 at a time
python3 gen.py jobs-icons.txt --1k      # 17 3D clay icons (1:1)
python3 gen.py jobs-empty.txt           # 4 empty states (4:3) + app icon (1:1), 2k
cd ../.. && python3 -I scripts/media/process.py   # WebP/PNG export, shrink originals, rebuild public/media/manifest.json
```

`gen.py` calls `python3 ~/.claude/skills/grok-imagine/scripts/generate.py PROMPT --out originals/<name>.jpg --aspect A --resolution 2k|1k --quality medium` for each job line (`name|aspect|prompt`).

## Video (Grok Imagine Video via Cloudflare AI Gateway)

`video.py NAME PROMPT [--image still.jpg] --model xai/grok-imagine-video|xai/grok-imagine-video-1.5-preview --duration 6 --aspect 16:9 --res 720p --via gateway` calls `POST /accounts/$ACCT/ai/run` with `{model, input:{prompt, image:{url:data-uri}, duration, aspect_ratio, resolution}}`.
Result on 2026-10-10: HTTP 400 `Zero Data Retention teams must provide output.upload_url for video generation.` for both models, so no video was produced. Unblocking needs a presigned PUT URL (R2 or GCS) passed as `input.output.upload_url`.

## Lights-out transition (`jobs-lightsout.txt`, Grok edit mode)

The 4th field of each job line is the source image, which switches `generate.py` to the edit endpoint (`--image`). Both edits start from the night hero, so the composition matches:

- **now/lightsout** (16:9, from `originals/now_night.jpg`) and **now/lightsout-phone** (9:16, from `originals/now_night-phone.jpg`): "Keep this exact scene, camera, composition, skyline shapes, palms, water and sky identical, but the city has a total power outage: every tower window and street light is dark, buildings become dark silhouettes, the water no longer reflects city lights, only faint moonlight and the last deep blue glow in the sky, and just three or four tiny warm candle glows in scattered windows. No text, no letters, no logos."

The two frames are tweened locally with ffmpeg: a 4 s blend with a flicker curve that plays once. Run it one job at a time, on local files only:

```bash
cd web/scripts/media/originals
F="if(lt(T,1.0),0,if(lt(T,1.12),1,if(lt(T,1.25),0.1,if(lt(T,1.33),0.9,if(lt(T,1.5),0.2,min(1,0.2+(T-1.5)/0.8))))))"
ffmpeg -y -loop 1 -framerate 30 -t 4 -i now_night.jpg -loop 1 -framerate 30 -t 4 -i now_lightsout.jpg \
  -filter_complex "[0:v]scale=1280:720,format=yuv420p[a];[1:v]scale=1280:720,format=yuv420p[b];[a][b]blend=all_expr='A*(1-($F))+B*($F)'" \
  -t 4 -c:v libx264 -crf 26 -preset veryfast -an -movflags +faststart -pix_fmt yuv420p ../../../public/media/now/lightsout.mp4
# phone: same command with now_night-phone.jpg / now_lightsout-phone.jpg, scale=720:1280, output lightsout-phone.mp4
```

I tried a WebM VP9 version. It came out larger than the MP4 (504 KB vs 447 KB), so I dropped it.

## App icon full-bleed edit

The first app icon came back as a tile inside a navy frame. I re-ran it through the edit endpoint to get a full-bleed square:

`generate.py "Recompose as a full-bleed square app icon: the deep night-blue gradient glass surface fills the entire square edge to edge, no inner tile, no border, no rounded corners, no drop shadow, no outer background. Keep the glowing coral ring, the small house and the water droplet exactly as they are, centered, with the ring spanning about 62 percent of the width. Soft 3D glass sheen, subtle inner glow. No text, no letters, no numbers." --image originals/app_icon.jpg --out originals/app_icon_fullbleed.jpg --aspect 1:1 --resolution 1k`

`process.py` exports these PNGs: apple-touch-icon-180, icon-192, icon-512 and favicon-32, all straight resizes. icon-maskable-512 puts the art at 390 px (76%, so 12% padding per side) on solid #0B0F17.
