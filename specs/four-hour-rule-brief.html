The 4-Hour Rule

Everything in your fridge and medicine cabinet has a clock.

The power is out and the apartment is 88°F. One photo of the open fridge, one of the medicine shelf. Gemma 4 lists every item. A rules engine built on USDA, FoodSafety.gov and FDA label text gives each item its own countdown, sorted by what dies first: SAFE, USE NOW, DISCARD. In English, Español and Kreyòl. Works offline inside Blackout Box.

Part A

Concept: for judges and the team

The problem

Checked this morning: Miami International read 87.8°F with a heat index of 97.7°F at 10:20 AM (NWS KMIA, from the Cold Chain brief). A closed refrigerator keeps food safe for only 4 hours without power (USDA via FoodSafety.gov). A full freezer, about 48 hours. Insulin labels cap room temperature at 86°F. After a hurricane, every one of those clocks is running at once and nobody can see them.

Who it is for

  • Everyone with a fridge. After an outage, the question is always "is this still good?" The official answer is a 60-row chart nobody reads by phone light.
  • Seniors managing meds alone, and anyone whose phone is on its last 10%.
  • Families with insulin or baby formula. Opened formula goes on the USDA discard list. Insulin has a label clock in days, not hours.
  • Spanish and Kreyòl speakers. Miami emergencies happen in three languages.

Why a clock, not a chatbot

  • People do not want a conversation at 2 AM with no AC. They want a list sorted by what dies first.
  • Every number comes from a rules table with a citation, never from the model. The model only reads the photo and writes the plain-language explanation.
  • When the engine is unsure about food, it says DISCARD. "When in Doubt, Throw it Out!" is the USDA line, verbatim.
  • When it is unsure about a medication, it says UNKNOWN: ask your pharmacist, and it never tells anyone to throw out insulin without a replacement (FDA emergency guidance).

How it works in 3 steps

01 · SNAP

Two photos

Open fridge (and freezer if you have one), then the medicine shelf. Gemma 4 (via the Gemini API online; gemma4:e4b on Ollama offline through Blackout Box) returns strict JSON: name, category, container, quantity, opened or not, visible brand text, confidence. It never assigns a limit.

02 · MATCH

Rules, not vibes

Code maps each food to a USDA FoodSafety.gov keep/discard class (hard cheese: keep; milk: discard after 4 h) using FoodKeeper keywords bundled in the repo. Each medication gets its openFDA label storage sentence (Lantus 28 d ≤86°F; amoxicillin suspension 14 d). Unknown food: DISCARD. Unknown med: UNKNOWN.

03 · COUNT DOWN

One sorted screen

You set when the power went out, tap "I opened the fridge" each time you do, and give an indoor temperature (or accept an estimate from NWS, labeled as an estimate). Every item gets a live clock and a status. Drag the outage slider and cards flip in real time.

Rules the product follows

  • Food bias: DISCARD when unsure. Unknown item, unknown class, unknown outage start → DISCARD with "USDA: when in doubt, throw it out." Never "probably fine".
  • Never suggest smelling or tasting. FoodSafety.gov: "never taste food to determine its safety."
  • Med bias: UNKNOWN, not DISCARD. No label text → "Ask your pharmacist." Insulin over its limit → PAST LABEL LIMIT: keep cool, check blood sugar, get a replacement; keep using only if no replacement (FDA). DO NOT USE only when frozen.
  • Every card shows the source sentence and where it came from (FoodSafety.gov chart row, FoodKeeper ID, or openFDA set_id).
  • The indoor temperature estimate is labeled "estimate" and the app asks for a thermometer reading first.
  • Door-open penalties and the 90% medication margin are our conservative choices, stated in the README, not USDA or FDA numbers.

Privacy and honesty

  • Photos are processed in memory and never stored. No accounts, no tracking. Offline mode sends nothing anywhere.
  • openFDA's disclaimer ("do not rely on openFDA to make decisions regarding medical care") is shown on the About screen and in the README.
  • FoodKeeper is a shelf-life table, not an outage table. The outage clocks come only from the FoodSafety.gov chart. Say so in the README.
  • Nutrition data (FoodData Central) is a demo nicety, not safety data. If it is on screen, it is clearly separate from the clock.

// engine/types.ts
export type Category = "food_refrigerated" | "food_frozen" | "food_shelf_stable" | "med_refrigerated" | "med_room_temp" | "unknown";
export type FoodClass =
  | "discard_4h"        // FoodSafety.gov "Discard" rows: meat, dairy, eggs, cut produce, cooked food, opened formula
  | "keep"              // "Keep" rows: hard cheese, butter, condiments, uncut produce, bread, PB
  | "mayo_8h_50f"       // opened mayo/tartar/horseradish: discard if above 50°F for more than 8 h
  | "frozen_refreeze"   // refreeze OK while ice crystals: meat, juices, breads, hard cheese
  | "frozen_discard"    // ice cream / frozen yogurt: discard once thawed
  | "frozen_veg_6h"     // frozen vegetables: discard after 6 h above 40°F
  | "shelf_stable"
  | "unknown";          // treated as discard_4h (bias to DISCARD)

export interface Item {
  id: string;                      // "f1", "m1"
  name: string;                    // as read: "2% milk"
  category: Category;
  container: "carton"|"bottle"|"jar"|"bag"|"box"|"tub"|"pen"|"vial"|"blister"|"other"|null;
  quantity: string|null;           // "1 gallon", "5 pens"
  opened: boolean|null;
  brandText: string|null;          // exact printed text, for openFDA / FoodKeeper lookup
  location: "fridge"|"freezer"|"door"|"shelf"|"cabinet"|null;
  confidence: number;              // 0..1 from the vision model
  foodClass?: FoodClass;           // set by classify(), never by the model
  foodkeeperId?: number|null;
  medRule?: MedRule;               // set from rules/meds.json or openFDA
  openedDaysAgo?: number|null;     // meds: user-entered; suspensions: days since mixed
  frozen?: boolean;                // meds: user says it froze
}

export interface MedRule {         // identical to Cold Chain's Rule
  kind: "refrigerated"|"room_temp"|"unknown";
  maxTempF: number|null; roomTempDays: number|null; inUseDays: number|null; doNotFreeze: boolean;
  quote: string; source: { setId: string; effectiveTime: string; field: string };
}

export interface Limit {
  kind: "fridge_4h"|"freezer_48h"|"freezer_24h"|"after_warm_8h"|"after_warm_6h"|"label_days"|"label_max_temp"|"none"|"unknown";
  hours: number|null;              // total allowance from outage start (food) or from fridge removal (meds)
  maxTempF: number|null;
  source: { name: string; url: string; quote: string; ref?: string };  // ref = chart row / FoodKeeper ID / set_id
}

export interface Outage {
  startedAt: string;               // ISO; user-entered
  doorOpens: string[];             // ISO timestamps of "I opened the fridge" taps

}

  indoorTempF: number|null;        // thermometer reading, or estimate

Engine (deterministic, conservative)

Food clocks (from FoodSafety.gov, verbatim)

  • "your refrigerator will keep food safe for up to 4 hours during a power outage. Keep the door closed as much as possible. Discard refrigerated perishable food such as meat, poultry, fish, eggs, and leftovers after 4 hours without power."
  • Chart column: "Exposed to temperatures of 40°F (4°C) or above for more than 2 hours" → the last 2 h of the 4 h window is USE NOW (cook it or move it to a cooler with ice).
  • "A full freezer will hold a safe temperature for approximately 48 hours (24 hours if it is half full and the door remains closed). Food may be safely refrozen if it still contains ice crystals or is at 40°F (4°C) or below".
  • Frozen vegetables: "Discard after held above 40°F (4°C) for 6 hours". Ice cream: discard even with ice crystals.
  • Opened mayonnaise, tartar sauce, horseradish: discard "if above 50°F (10°C) for more than 8 hrs".

Our conservative choices (state them in the README)

  • DOOR_OPEN_PENALTY_H = 0.5 per tap, capped at 2 h total, applied to the fridge and freezer clocks separately. Not a USDA number.
  • Mayo and frozen-vegetable rules start their 8 h / 6 h counters after the fridge (4 h) or freezer (48/24 h) window ends. Our assumption of when the box passes 40°F / 50°F.
  • FREEZER_USE_NOW_H = 12: last 12 h of the freezer window is USE NOW ("cook it or add ice"). Our number.
  • Unknown or low-confidence food (< 0.5) is discard_4h.
  • Meds: SAFETY_MARGIN = 0.9, shortest limit when a label covers several products, every hour since outage counts as room temperature (all from Cold Chain).
  • If the user never set an outage start, every refrigerated food is DISCARD and every refrigerated med is UNKNOWN until they do.
// engine/assess.ts (pure; no I/O; same file ships as skills/four-hour-rule/scripts/assess.mjs)
import { verdict as medVerdict } from "./medVerdict";   // Cold Chain engine.mjs, unchanged
export const FRIDGE_H = 4, FRIDGE_USE_NOW_H = 2, FREEZER_FULL_H = 48, FREEZER_HALF_H = 24, FREEZER_USE_NOW_H = 12;
export const DOOR_OPEN_PENALTY_H = 0.5, DOOR_OPEN_CAP_H = 2, MAYO_AFTER_WARM_H = 8, FROZEN_VEG_AFTER_WARM_H = 6;
const FS = "https://www.foodsafety.gov/food-safety-charts/food-safety-during-power-outage";

export function assess(items, outage, env, now = Date.now()) {
  const t0 = Date.parse(outage.startedAt);
  const hoursOut = Number.isFinite(t0) ? Math.max(0, (now - t0) / 36e5) : null;
  const pen = (opens) => Math.min(DOOR_OPEN_CAP_H, (opens?.length ?? 0) * DOOR_OPEN_PENALTY_H);
  const fridgeH  = FRIDGE_H - pen(outage.doorOpens);
  const freezerH = (outage.freezerFull ? FREEZER_FULL_H : FREEZER_HALF_H) - pen(outage.freezerDoorOpens);

  const out = items.map((it) => {
    const a = [];
    if (it.category.startsWith("med")) return medCard(it, hoursOut, env, now, a);
    if (hoursOut == null) return v(it, "DISCARD", 0, lim("unknown", null, "No outage start time"), ["no_outage_start"], a);
    const cls = it.foodClass ?? "unknown";
    if (cls === "unknown") a.push("unknown_item_discard");
    if (outage.doorOpens?.length) a.push("door_open_penalty");
    switch (cls) {
      case "shelf_stable": case "keep":
        return v(it, "SAFE", null, lim("none", null, cls === "keep" ? "USDA chart: Keep" : "Shelf stable"), [], a);
      case "mayo_8h_50f":
        return clock(it, fridgeH + MAYO_AFTER_WARM_H, hoursOut, FRIDGE_USE_NOW_H, "after_warm_8h",
          "Opened mayonnaise, tartar sauce, horseradish: Discard (if above 50°F (10°C) for more than 8 hrs)", a.concat("warm_start_assumed"));
      case "frozen_refreeze": case "frozen_discard":
        return clock(it, freezerH, hoursOut, FREEZER_USE_NOW_H, outage.freezerFull ? "freezer_48h" : "freezer_24h",
          "A full freezer will hold a safe temperature for approximately 48 hours (24 hours if it is half full and the door remains closed).",
          a, cls === "frozen_refreeze" ? ["check_ice_crystals_refreeze_ok"] : ["ice_cream_discard_if_thawed"]);
      case "frozen_veg_6h":
        return clock(it, freezerH + FROZEN_VEG_AFTER_WARM_H, hoursOut, FREEZER_USE_NOW_H, "after_warm_6h",
          "Vegetables: Discard after held above 40°F (4°C) for 6 hours", a.concat("warm_start_assumed"));
      default: // discard_4h and unknown
        return clock(it, fridgeH, hoursOut, FRIDGE_USE_NOW_H, "fridge_4h",
          "Discard refrigerated perishable food such as meat, poultry, fish, eggs, and leftovers after 4 hours without power.", a);
    }
  });
  return out.sort(order);
}

function clock(it, allowH, hoursOut, useNowH, kind, quote, assumptions, extraReasons = []) {
  const left = allowH - hoursOut;
  const status = left <= 0 ? "DISCARD" : left <= useNowH ? "USE_NOW" : "SAFE";
  return v(it, status, Math.max(0, left), lim(kind, allowH, quote), extraReasons, assumptions);
}
function medCard(it, hoursOut, env, now, a) {
  if (!it.medRule || it.medRule.kind === "unknown") return v(it, "UNKNOWN", null, lim("unknown", null, "No label storage text"), ["ask_pharmacist"], a);
  if (hoursOut == null || env.indoorTempF == null) return v(it, "UNKNOWN", null, lim("unknown", null, it.medRule.quote), ["need_outage_and_temp"], a);
  if (env.indoorSource === "estimate") a.push("indoor_estimate");
  const r = medVerdict(it.medRule, { indoorTempF: env.indoorTempF, indoorSource: env.indoorSource, hoursOutOfFridge: hoursOut,
                                     openedDaysAgo: it.openedDaysAgo, frozen: it.frozen, forecastIndoorF: env.forecastIndoorF }, now);
  const map = { OK: "SAFE", USE_SOON: "USE_NOW", OVER_LIMIT: "PAST_LIMIT", DO_NOT_USE: "DO_NOT_USE", UNKNOWN: "UNKNOWN" };
  const kind = r.status === "OVER_LIMIT" && r.reasons.includes("temp_above_label_max") ? "label_max_temp" : "label_days";
  return v(it, map[r.status], r.hoursLeft, { kind, hours: it.medRule.roomTempDays ? it.medRule.roomTempDays * 24 * 0.9 : null,
           maxTempF: it.medRule.maxTempF, source: { name: "FDA label (openFDA)", url: "https://api.fda.gov/drug/label.json",
           quote: it.medRule.quote, ref: it.medRule.source.setId } }, r.reasons, a.concat("safety_margin_0_9"));
}
function lim(kind, hours, quote) { return { kind, hours, maxTempF: null, source: { name: "FoodSafety.gov (USDA)", url: FS, quote } }; }
function v(it, status, hoursLeft, limit, reasons, assumptions) {
  return { itemId: it.id, status, hoursLeft, expiresAt: hoursLeft == null ? null : new Date(Date.now() + hoursLeft * 36e5).toISOString(), limit, reasons, assumptions };
}
const RANK = { DO_NOT_USE: 0, DISCARD: 0, PAST_LIMIT: 0, USE_NOW: 1, SAFE: 2, UNKNOWN: 3 };
function order(a, b) {
  if (RANK[a.status] !== RANK[b.status]) return RANK[a.status] - RANK[b.status];
  if (a.hoursLeft == null) return b.hoursLeft == null ? 0 : 1;
  if (b.hoursLeft == null) return -1;
  return a.hoursLeft - b.hoursLeft;
}
